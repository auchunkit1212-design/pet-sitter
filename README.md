# 90s Pet Sitter

90後年輕寵物保姆網站｜全港上門放狗、放貓、餵食、陪伴。

## 本機開發

```bash
npm install
npm run dev
```

## 建置

```bash
npm run build
npm run preview
```

## 部署到 GitHub Pages

```bash
npm run deploy
```

網站會發布到：`https://auchunkit1212-design.github.io/pet-sitter/`
